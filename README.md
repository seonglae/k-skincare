# k-skincare

Evidence-based K-skincare consultation skill + CLI. Korean dermatology protocols filtered by RCTs.

## Install

```bash
npx @seonglae/k-skincare
```

## What it does

Interactive CLI. Takes your age, skin type, concerns, current products → returns personalized AM/PM routine + shopping list + RCT evidence.

## Why

K-beauty marketing is everywhere. RCT evidence is buried. This tool filters: only interventions with peer-reviewed effect sizes get recommended.

## Evidence base

`evidence/` directory contains 69+ peer-reviewed papers across 6 skincare domains + 6 nutrition/supplement domains. All PMIDs/DOIs verified.
