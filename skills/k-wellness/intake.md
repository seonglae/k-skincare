# Intake Form — k-wellness

**Conduct entire intake in user's detected language.** Translate questions at runtime. Do NOT show this template verbatim — adapt to natural conversational flow.

---

## Tier 1 — Essential (6 questions, ALWAYS ask)

Required for any plan.

1. **Demographics**: Age + sex + height + weight + country/city
   - Why: BMR/TDEE for diet, climate (Vit D latitude), healthcare access

2. **Top concern(s) ranked**: Sleep / energy / weight / stress / mood / GI / vision / other
   - Probe: "1-3 priority ranking"

3. **Sleep pattern**: Typical bedtime / wake time / quality 1-10 / how rested on wake
   - Trigger questions: delayed onset? frequent waking? snoring? early waking?

4. **Daily activity**: Sedentary office / light active / moderate / vigorous
   - Exercise: cardio/strength/walking/none — frequency + duration

5. **Current supplements + Rx medications**: list everything (mg + timing + duration)
   - Critical for interactions
   - Include OTC analgesics, antacids, vitamins

6. **Known conditions + allergies**:
   - Diagnosed conditions (asthma, IBS, GERD, anxiety/depression dx, hypothyroid, etc.)
   - Drug allergies + food intolerances
   - Recent labs (Vit D, ferritin, TSH, ALT/AST) if available — ask user to share values

---

## Tier 2 — Refinement (12 questions, ask if user wants detailed plan)

Trigger after Tier 1: "Want a more precise plan? 12 more questions, ~5 min."

7. **Diet patterns**:
   - Meal times (breakfast / lunch / dinner) + snacks
   - Protein source frequency (meat / fish / legumes / dairy)
   - Vegetable / fruit servings per day
   - Carbohydrate type (white rice / whole grain / refined / RS — cooled rice/potato)
   - Estimated daily caffeine + alcohol
   - Hydration

8. **Sleep environment + behaviors**:
   - Bedroom temperature, light, noise
   - Screen use 1h pre-bed (phone, TV, gaming)
   - Bedtime routine (read, music, meditation)
   - Wake light exposure (morning sun)

9. **Stress signals**:
   - Hyperventilation episodes? Frequency? Triggers?
   - Panic attacks? Heart racing? Chest tightness?
   - Chronic muscle tension (neck, jaw, shoulders)?
   - Stress eating / under-eating under stress?

10. **GI symptoms**:
    - Bloating, gas (odor severity), frequency
    - Stool form (Bristol type 1-7)
    - Food triggers identified?
    - Reflux / heartburn / nausea?
    - Recent antibiotics?

11. **Energy + fatigue pattern**:
    - AM grogginess severity / duration
    - Mid-afternoon crash?
    - Evening second wind (wired but tired)?
    - Crash after specific foods?

12. **Body composition goals**:
    - Goal: cut / maintain / bulk / recomp
    - Current waist circumference if known
    - Recent weight trajectory (last 3-6 months)
    - History of dieting attempts

13. **Vision / eye fatigue**:
    - Screen time per day (work + leisure)
    - Blurriness when fatigued?
    - Dry eyes? Lubricant drops use?
    - Recent eye exam?

14. **Cycle / hormonal context** (if applicable to user):
    - Menstrual regularity
    - PMS / PMDD symptoms
    - Contraceptive use (affects nutrient needs)
    - Or for male: libido / morning erections (cortisol / testosterone signals)

15. **Caffeine + alcohol detail**:
    - Caffeine: source (coffee/tea/energy/soda), mg, last time
    - Alcohol: drinks/week, type, with food vs alone

16. **Smoking / vaping / cannabis**: frequency + duration

17. **Mood baseline 1-10** (not asking for diagnosis, just self-report)

18. **Goal commitments**: how aggressive vs comfortable
    - "I want strict protocol" vs "I want sustainable"

---

## Tier 3 — Labs + meds deep-dive (5 questions, IF Tier 2 shows complexity)

19. **Recent blood test values** (request user share):
    - 25(OH) Vit D
    - Ferritin / serum iron
    - TSH (and free T4 if available)
    - ALT / AST (for any liver-metabolized supplement)
    - HbA1c / fasting glucose
    - Lipid panel
    - CBC

20. **Family history**: cardiovascular, diabetes, autoimmune (esp Hashimoto's), neurodegenerative, mood disorders

21. **Past Rx history** (last 5 years): SSRIs, benzos, sleep meds, hormonal, corticosteroids

22. **Sleep diagnostics done?**: home sleep study / PSG / actigraphy
23. **Existing wearables data**: Apple Watch / Oura / Whoop sleep data? HRV trends?

---

## Behavior rules

- **Don't ask all at once**. One batch at a time, conversational.
- **Tier 1 → basic plan → offer Tier 2** (no auto-cascade).
- **Skip irrelevant questions** (e.g. cycle Qs if not applicable).
- **Probe vague answers**: "tired" → AM grogginess vs afternoon crash vs evening fatigue?
- **Save context mentally** — don't re-ask.
- **Multi-language**: translate every question; keep technical terms (NAC, KSM-66, mg, EPA, DHA, glycine) in English with brief native gloss.

## Anti-patterns

- ❌ Long bullet-form dump
- ❌ Medical diagnosis attempts (refer GP)
- ❌ "Drink water + sleep more" generic advice
- ❌ Supplement recommendations without checking Rx interactions
- ❌ Aggressive cutting plans without screening for ED signals
- ❌ Override user's diagnosed conditions (e.g. ignore IBS diagnosis when recommending FODMAP)
